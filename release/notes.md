# v0.4.1

适配 codex-proxy-rs v3.32.0 起的插件 RPC 协议 v6/v7，使用 v3.33.0 SDK（commit `8c8618aa0f841638262262e3338c115bc075f125`）。

## 升级说明

- 宿主 3.33.0+ 必须使用 v0.4.1 或后续兼容版本；宿主 3.29.7～3.31.3 请指定标签 `v0.4.0`；宿主 3.29.0～3.29.6 请指定标签 `v0.3.0`；宿主 3.18.0～3.28.x 请指定标签 `v0.2.1`
- 插件 RPC 协议由 v5 升至 v7；洋葱中间件能力合同由 5 升至 6，`observer` 2、`management` 2 不变
- 仅修改清单版本号不能完成升级，必须使用新 SDK 重新构建的安装包
- 业务行为、私有状态格式及页面 API 保持兼容，已有私有状态（含历史 SSE 观测）持续可读

## 内部变更

- SDK 提交 `76291f44` → `8c8618aa`（协议 v5 → v7）
- 适配协议 v7 的协作式调度：插件让出执行名额时宿主应答恢复授权，测试宿主替身支持 `suspend` / `resume` / `callback_consumed`
- 适配协议 v7 的按阶段处理预算：宿主声明的 `timeout_ms` 不得超过该阶段默认预算，观测阶段预算为 2000 ms
- 观测事件移除上游响应模型字段（`response_model`），实际发送模型仍取 `upstream_model`
- 后端编译、测试、脚本与文档中的协议版本断言全部更新为 v7
