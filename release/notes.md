# v0.2.1

## 修复

- 账号显示统一为「邮箱优先、名称其次、ID 兜底」，修复有邮箱的账号仍显示通用 OAuth 名称的问题；邮箱和名称均去除首尾空白，缺失或全空白时回退到原账号 ID。
- `api/overview` 与 `api/accounts` 复用同一规则，继续通过现有 `accountName` 字段显示完整邮箱，不增加独立邮箱或凭据字段；同一邮箱的不同账号仍按 ID 分开。
- 不修改前端 UI、宿主账号资料或持久化记录。插件身份、状态 schemaVersion 1、宿主要求 `>=3.18.0` 及固定的 v3.18.2 SDK 提交均不变，已有配置与历史继续可读。

## 验证

- 新增两接口的管理协议回归矩阵，覆盖邮箱优先、空白处理、名称/ID 回退、同邮箱不同 ID 及字段边界；云端冒烟增加 56 个账号目录与三页概况的精确标签断言，保留 HTTP/WS、设置、CAS 和 State 隐私检查。
- 完整测试、Linux x86_64 GNU（glibc 2.28 基线）构建、真实 release 二进制冒烟、官方打包与附件回读校验均由 GitHub Actions 在云端执行，全部通过后才公开 Release；运行结果见本版本对应的 Actions 记录。
- 未操作生产宿主，也未进行真实上游流量验收。
