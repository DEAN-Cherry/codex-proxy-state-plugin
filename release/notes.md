# v0.3.0

## 修复

- 适配 codex-proxy-rs v3.29 起的插件 RPC 协议 v4：插件改用上游 v3.29.2 SDK（提交 `2221f400da29731c8f62464dd097945b85cf82f1`）重新构建，握手协议版本由 2 升为 4，帧载荷按新布局编码。
- 能力合同同步升级：`middleware` 3 → 5、`observer` 1 → 2、`management` 1 → 2；安装包由官方 CLI 重新生成并写入新的协议版本。
- 宿主版本要求改为 `>=3.29.0`。协议 v4 与旧宿主不互通，宿主 3.18.0～3.28.x 请继续使用 `v0.2.1`，3.15.2～3.17.x 使用 `v0.1.3`。
- 业务行为、管理 API 结构、私有状态 schemaVersion 1 与插件身份均不变；已有配置和观测历史继续可读。

## 验证

- 后端完整测试（含协议握手、HTTP/WS 观测、设置 CAS、重启恢复）与 Clippy、格式检查通过；前端 lint、13 项测试与构建通过。
- 本地 QA 替身按协议 v4 帧布局重写，真实插件进程完成注册、管理路由、观测与隐私检查。
- Linux x86_64 GNU（glibc 2.28 基线）构建、release 二进制冒烟、官方打包与附件回读校验由 GitHub Actions 云端执行，全部通过后才公开 Release；运行结果见本版本对应的 Actions 记录。
- 未操作生产宿主，也未进行真实上游流量验收。
