# v0.1.2

## 功能

- 默认聚合全部账号，外层按账号分组，内层展示各模型的 State 长度、观测状态、保留样本和最后观测时间
- 账号名称作为主标题，ID 辅助区分同名账号，缺少名称时回退到 ID；配置与历史始终按 ID 关联
- 支持名称或 ID、模型和状态筛选，按账号整组分页，账号组默认展开并可折叠
- 保留停用、未观测和读取失败的账号，明确区分加载中的部分结果与全局总计
- 按需打开账号详情与配置，并发保存冲突保留草稿，恢复操作固定在弹窗页脚

## 响应流修复

- 修复 0.1.0 在官方 3.15.2 上包装响应正文时，内部空 `RawBytes` 控制帧被 SSE/JSON 正文回调拒绝并导致流关闭的问题
- 不再使用 `inspect_frames`，原样归还未读取的宿主正文句柄，保留宿主对流、取消和终态的所有权
- 改用 WebSocket 旁路观察，根据实际 attempt、账号及映射模型归属 State，不根据请求别名或响应模型猜测

## 安装

支持宿主 `>=3.15.2, <3.16.0`，本次附件仅适用于 Linux x86_64 GNU，最低 glibc 2.28。
在宿主「插件管理 → 安装 → GitHub」中填写：

```text
DEAN-Cherry/codex-proxy-state-plugin
```

标签可留空查询最新稳定版，或明确填写 `v0.1.2`。
也可下载本 Release 的 `.tar.gz` 附件并上传安装，不要使用 Source code 归档。
`.sha256` 附件用于校验下载内容。

插件 ID 仍为 `dean-cherry.state-observer`，原有账号配置和私有记录 schema 保持兼容。
安装后核对访问域、实例状态和新增的 WebSocket 观察绑定，再从插件导航打开「State 观测」。

## 升级注意事项

- **权限变化：** 保留 `requests`，将 `data` 替换为 `accounts`。官方 3.15.2 的 data 目录没有名称，因此通过 `host.auth.list` 读取非凭据运行投影。accounts 授权域本身也包含原始凭据访问和账号修改能力，安装时需要重新核对并接受；本插件不调用读取原始凭据或修改账号的接口。
- **采集范围：** 保留响应 Header 和可见的 WebSocket 旁路元数据，不再采集仅存在于 HTTP/SSE 正文中的 State，历史 SSE 摘要仍可查看。
- **失败策略：** 宿主会保留原有绑定的范围和策略，插件不会擅自修改默认 `reject`。观察用途建议 request/attempt 采用 `delegate`、观察阶段保留 `observe`；`delegate` 只在调用 next 前允许安全委托，不能替代正文所有权修复。
- 官方 3.15.2 可能隐藏此插件的设置入口，README 提供了保留绑定范围、敏感值并使用 `expectedRevision` 更新的官方实例 API 操作说明。

## 行为边界

- 被动记录业务响应，不主动刷票、不重写请求、不改变账号调度或计费
- 不保存 State 原文，仅保存字节长度和摘要指纹
- 每账号最多保留最近 16 个模型，每模型最多 12 条摘要，统计仅覆盖保留窗口内的有界样本
- 保留时间可设为 1～168 小时，是本地观测期限，不代表上游 State 有效期
- 上游过滤的部分 metadata 对插件不可见，未观测到 State 不表示账号异常
- 不支持没有插件运行时的 fork 3.13.3，本插件不执行宿主升级或数据库迁移
