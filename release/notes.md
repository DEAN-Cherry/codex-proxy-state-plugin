# v0.4.0

适配 codex-proxy-rs v3.29.7 起的插件 RPC 协议 v5，使用 v3.30.2 SDK（commit `76291f448cdf1d1da2027da32b7c949deb998c7a`）。

## 升级说明

- 宿主 3.29.7+ 必须使用 v0.4.0 或后续兼容版本；宿主 3.29.0～3.29.6 请指定标签 `v0.3.0`；宿主 3.18.0～3.28.x 请指定标签 `v0.2.1`
- 插件 RPC 协议由 v4 升至 v5，能力合同 `middleware` 5、`observer` 2、`management` 2 保持不变
- 业务行为、私有状态格式及页面 API 保持兼容，已有私有状态（含历史 SSE 观测）持续可读

## 页面改进

- 首页默认只显示有效 State；过期模型收进账号「详情与配置」的「历史 State」分区
- 新增「过期展示期限」选项（仅显示有效 / 1 小时 / 6 小时 / 24 小时 / 7 天），过期未超期限的模型仍留在首页，偏好保存在本机浏览器
- 状态筛选选「已过期」时仍会列出全部过期模型；只剩历史 State 的账号在首页显示「历史 State N」标记

## 内部变更

- SDK 提交 `2221f400` → `76291f44`（协议 v4 → v5）
- 后端编译、测试、脚本与文档中的协议版本断言全部更新为 v5
- CI/CD 流水线保持不变，发布流程与冒烟测试适配新协议
