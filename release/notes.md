# v0.1.3

## 兼容性

- 移除宿主版本上限，`engines` 由 `>=3.15.2, <3.16.0` 改为 `>=3.15.2`；已发布的 v0.1.2 在 3.16 及以上宿主会被拒绝加载，需安装本版本
- SDK 固定到 codex-proxy-rs v3.17.0（`3915aa259bb558bb285784b57ba6b3b43abefd93`），插件使用的接口在 3.15.2 至 3.17.0 间无变化
- 新增清单回归测试，覆盖 3.15.2、3.16.0、3.17.0、4.0.0 及基线以下版本
- 权限仍为 `requests` 与 `accounts`；宿主 v3.17.0 的 `data` 账号事实不含名称，暂不替换 `accounts`

## 文档

- README 精简为用户安装、使用与限制说明，开发、构建和打包命令移至 `docs/development.md`

## 升级注意事项

插件 ID、账号配置与私有记录 schema 不变，管理 API、采集范围和行为边界与 v0.1.2 一致。
升级后核对访问域与实例绑定；失败策略建议仍见 README。

## 验证

本地 Rustfmt、全目标 Clippy、后端测试与 release 构建通过，前端测试、lint 和构建通过；
本地 QA 宿主以 release 二进制完成管理路由往返。
未在 Linux 正式宿主上安装，也未经真实上游流量验证，请在目标环境完成验收。
